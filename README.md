# 🚀 AI 주식 투자 분석 RICE 통합 프롬프트 생성기 (All-in-One)

> **1장 모닝브리핑부터 13장 미래지도까지**, 모든 AI(Gemini, ChatGPT, Claude) 주식 분석 프롬프트를 하나의 통합 웹 애플리케이션에서 자유롭게 생성하고 즉시 실행할 수 있습니다.

---

## 🌟 주요 특징

1. **13개 전 챕터 올인원 통합**
   - 기존의 파편화된 링크들을 하나의 매끄러운 단일 웹 애플리케이션으로 통합
   - 상단 반응형 탭과 홈 카드를 통해 원하는 분석 챕터로 언제든 1초 만에 전환
2. **모바일 & PC 완벽 반응형 UI**
   - **스마트폰/태블릿**: 한 손 조작 터치 친화적 버튼, 부드러운 가로 스와이프 탭, 직관적인 옵션 선택
   - **PC/데스크톱**: 시원한 대화면 파이낸셜 대시보드 레이아웃, 프롬프트 실시간 확인 및 복사
3. **스마트 AI 연동 & 원클릭 복사**
   - **[📋 클립보드 복사]**: 모던 Clipboard API 기반 부드러운 토스트 알림
   - **[✨ Gemini 열기]**: Google Gemini 웹으로 자동 복사 후 즉시 이동 (`Ctrl+V`로 바로 분석 시작)
   - **[🤖 ChatGPT 열기]**, **[🟣 Claude 열기]** 원클릭 바로가기 지원
4. **100% 완전 무료 & 오프라인 실행 가능**
   - 인증 제한이나 유료 안내 팝업을 전면 해제하여 모든 기능을 영구 무료로 사용 가능
   - `index.html` 단일 파일로 구성되어 별도의 서버 설치 없이 브라우저에서 바로 열 수 있으며, Netlify, Vercel, GitHub Pages 어디든 즉시 배포 가능

## 💻 실행 방법

### 방법 1: 브라우저에서 바로 열기
- 작업 폴더 내의 [`index.html`](file:///c:/Antigravity/10_AEGNT%20AI%20UPGARED/index.html) 파일을 더블 클릭하여 크롬, 엣지, 사파리 등의 브라우저에서 바로 사용합니다.

### 방법 2: 로컬 웹 서버로 실행
```bash
# 파이썬 내장 서버 실행
python -m http.server 8000

# 브라우저에서 접속
http://localhost:8000/index.html
```

## ⚡ 키움증권 실시간 시세 연동 가이드

1. **키움증권 프록시 서버 실행 (CORS 우회 & API 중계)**:
   ```bash
   python kiwoom_proxy.py
   ```
   * 터미널에서 위 명령어를 실행하면 `http://localhost:5000`에서 가벼운 프록시 서버가 가동됩니다.
2. **웹 화면에서 키움 API 설정**:
   * 브라우저에서 `index.html`을 열고, 시세 영역 우측의 **[⚙️ 키움 설정]** 버튼을 클릭합니다.
   * 발급받으신 **App Key**와 **Secret Key**를 입력한 후 **[설정 저장]**을 누릅니다.
   * [연결 확인] 버튼을 눌러 프록시 서버 연결 상태를 테스트할 수 있습니다.
3. **실시간 시세 조회**:
   * 종목(예: 삼성전자, 삼성바이오로직스 등)을 선택하고 **[⚡ 실시간 가격 가져오기]**를 누르면 키움증권의 최신 주가가 조회되어 AI 프롬프트에 자동으로 주입됩니다.
